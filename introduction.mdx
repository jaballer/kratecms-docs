KrateCMS gives your team a fully featured content management system accessible from any browser. From the moment you log in, you can publish posts, build pages from modular blocks, chat with an AI assistant, query your content through an API, and customize every visual detail of your site — no command line required.

## What you get

### Posts and pages

Create posts with the Tiptap rich-text editor. Add a featured image, assign a category (text, audio, video, or uncategorized), embed YouTube videos or SoundCloud tracks, and control whether each post is public or members-only. A draft/published workflow lets you stage content before it goes live, and every post gets a clean slug-based URL.

Pages work differently — they are built from a modular block library. Drag and drop rich text, images, calls to action, two-column layouts, video embeds, audio players, quote blocks, accordions, hero banners, media-and-content panels, and embedded contact forms — plus a Custom HTML block for anything else, from a booking widget or map embed to your own markup and scripts. You can reorder blocks at any time, collapse them while editing, and toggle the page title off for hero-first designs.

### Configurable homepage

Choose what visitors see when they land on your site: a scrolling posts feed (the default), a legacy marketing template, any Page you have built — just like WordPress's "page as homepage" option — or a shareable [Krate page](/content/krate-page). Switch between them any time from **Settings → Content**.

### Media library

Every file your site uploads — featured images, inline images, page-block images, and audio — lands in a searchable [media library](/content/media-library). Browse it as a grid or a list, filter by type and source, and reuse any asset instead of uploading it twice. Describe an image once and every featured-image and page-block placement of it picks that description up (inline images inside post content keep their own). Trash and restore keep the library tidy without destroying anything a published page still uses.

### AI tools

KrateCMS includes a real-time AI chat interface powered by OpenAI. You can hold conversations, and enable agent mode — where the AI creates, searches, updates, and lists your **posts and pages** on your behalf through tool-calling, under exactly the permissions your account already has. Token usage is tracked per message.

Beyond the admin, the built-in [MCP server](/integrations/mcp) connects an outside AI client — like Claude — directly to your posts, media library, and release notes.

### REST API

Every tenant gets a versioned REST API at `/api/v1/` covering [posts](/api/posts), [media](/api/media), and [release notes](/api/release-notes). Post and release-note reads are public and need no credentials; writes, and every media call, use a Sanctum token. An OpenAPI 3.1 specification and a Postman collection are included.

### Brand and settings

Customize your site's colors, typography, logo, favicon, theme mode, and inject custom CSS — all from **Settings → Brand**. Build your header and footer navigation in the menu builder under **Settings → Menus**. Set upload size and file type limits under **Settings → Media**, and connect your own Google Tag Manager container under **Settings → Tracking Tags**. General settings cover the site name, description, footer text, and business details; security settings control login attempt limits, session timeouts, and password policies.

## Roles and what they can do

KrateCMS uses seven roles. Your role is set when your account is created and can only be changed by an admin.

| Role | What they can do |
|---|---|
| **super-admin** | Full platform access; bypasses all permission checks |
| **admin** | All permissions across content, users, and settings |
| **manager** | Posts, pages, and the media library; can view users |
| **editor** | Posts, pages, and the media library |
| **author** | Their own posts only — no pages, no media library |
| **contributor** | Can create and edit their own posts; cannot publish |
| **viewer** | Read-only access to published posts |

<Note>
  Contributors can draft posts but cannot publish them. An editor, manager, or admin must publish a contributor's work.
</Note>

## Feature availability

Some features are enabled per site rather than shipped to everyone. If a settings category or sidebar link is missing, it hasn't been turned on for your site — contact your platform administrator to request it.

| Feature | How it's enabled |
|---|---|
| [Tracking Tags](/settings/tracking-tags) | Enabled per site |
| [Custom Domains](/settings/custom-domains) | Enabled per site |
| [AI Chat](/ai/chat) | Enabled per site |
| [AI featured images](/ai/image-generation) | Off platform-wide — not a per-site switch |
| [Billing](/settings/billing) | Off platform-wide — not yet offered to sites |
